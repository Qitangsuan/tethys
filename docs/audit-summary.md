## 关键发现

### 1. 规则 7 的真相（最重要）

- 窗口 10 时「edit 前读同文件」只有 32.5%；**放大到不限窗口后 60.8%** → 之前「三分之二没读就改」是**测量误差**（read 离 edit 远、路径匹配漏）。
- 剩余 39.2% 无前置 read 的 edit **大多成功**——说明 DSH 的 edit 靠 `old_string` 匹配，不强制先读；「先读」是**最佳实践而非必要约束**。
- edit_no_match 失败链：**37.5% 失败前读过同文件**（= 文件变了，不是没读）；**62.5% 失败后会重读**、75% 重试 edit——**失败分诊行为已在执行**。
- 所以规则 7「理论收益 #1」的上限假设不成立；它的实际价值集中在「失败后重读再改」，而这部分已被执行。

### 2. 失败构成：环境类占大头

`exit_code 26.3% + read 15.7% + web 9.6% + 网络 5.5% + 配置/子代理 9.9% ≈ 67%` 是环境/工具/配置类失败——**规则能管的（edit 13.7% + 工具标识符 4.4%）约占 18%**。潮汐的规则策略有天然天花板。

### 3. 模型观察（不可当结论）

- deepseek-flash：2.61%（样本充分）。
- qwen3.8-flash：9.16%——但样本只有 393 次且被分配了 Cordis inspect 类难任务（**任务偏差**），不能读成「模型差」。
- 其他模型样本 <400，失败率仅供参考。
